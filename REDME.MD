
# DS Sales Management System

## Project Overview
A Sales Management System developed using Python, Flask and MySQL.

## Technologies Used
- Python
- Flask
- MySQL
- Pandas
- Matplotlib

## Project Features
- Sales Dashboard
- Total Revenue Calculation
- Customer Details
- Product Details
- Sales Records
- Sales Analysis
- Category-wise Revenue Chart
- Product-wise Sales Chart

## Database Tables
- Customers
- Products
- Sales

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Create database using schema.sql.

3. Run the application:
   python app.py

4. Open browser:
   http://127.0.0.1:5000
